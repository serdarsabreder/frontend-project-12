## Hexlet Chat

Chat application built with React, Vite and the Hexlet chat server.

### Deployed application

Deployed app: [https://frontend-project-12.onrender.com](https://frontend-project-12.onrender.com)

### Commands

- `make install` — install dependencies
- `make build` — build the frontend application
- `make start` — start the server and serve the built application on port 5001
- `make lint` — run the linter
